# Brand reference provenance

The three boards in `reference/` were supplied by the project owner in the project conversation as visual references. They are not production logo files. The application renders a simple code-native mark and text; no third-party screenshot or Refero image is bundled as product artwork. Brand names and marks are not granted for unrelated branding by the Apache-2.0 source license. Review ownership and any embedded font/image rights before redistributing these reference boards as assets.
